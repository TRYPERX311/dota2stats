# Чек-лист: Список пользователей


**Модуль:** Список пользователей

**Приоритет:** Высокий

**Окружение:** Production / Local


## Отображение

- [ ] Страница `/users` загружается без ошибок

- [ ] Список отображается для гостя

- [ ] Список отображается для авторизованного

- [ ] Гость и авторизованный видят одинаковый список

- [ ] Для авторизованного его карточка в списке выделена обводкой, отображается подпись (вы) рядом с ником


## Карточка пользователя


- [ ] Отображается ник

- [ ] Отображается аватар

- [ ] Отображается когда обновлялась статистика

## Сортировка

- [ ] Сортировка по дате авторизации

- [ ] Порядок: от старых к новым

- [ ] Новый пользователь появляется снизу

- [ ] При равных датах порядок стабильный


## Клик по пользователю

- [ ] Клик → переход на профиль пользователя

- [ ] Открывается именно тот пользователь, по кому кликнули

## Пустое состояние

- [ ] Если пользователей нет → пустой список (не белый экран)

- [ ] Вёрстка не ломается при пустом списке



## API

- [ ] `GET /users` авторизованный → 200 OK
- [ ] `GET /users` без авторизации → 200 ОК
- [ ] Ответ — JSON-массив
- [ ] Поля: `id`, `nickname`, `avatar`, `account_id`, `last_updated`

## Граничные случаи

- [ ] 1 пользователь → список из 1 элемента

- [ ] Много пользователей (10+) → вёрстка не ломается

- [ ] Длинный ник → не вылезает за карточку

- [ ] Отсутствующий аватар → заглушка

- [ ] Удалённый пользователь в URL → 404



## Известные ограничения

- Пагинация отсутствует

- Фильтры отсутствуют
