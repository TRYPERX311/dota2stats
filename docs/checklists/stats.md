# Чек-лист: Статистика

**Модуль:** Статистика

**Приоритет:** Высокий

**Окружение:** Production / Local

## Общие проверки

- [ ] Статистика матчей отображается одинаково у гостя и авторизованного
- [ ] Все блоки статистики прогружаются без ошибок в консоли
- [ ] Нет «зависших» skeleton-загрузок
- [ ] Данные консистентны между блоками (общая статистика ↔ патч ↔ герои)

## Общая статистика (за всё время)

- [ ] Отображается счётчик W-L (победы-поражения)
- [ ] Победы выделены зелёным
- [ ] Поражения выделены красным
- [ ] Отображается процент побед (WR)
  - [ ] Отображается общее число игр
  - [ ] Сумма W + L = общее число игр
- [ ] WR рассчитывается как `wins / total * 100`, округление корректное
- [ ] Отображается средний KDA
- [ ] KDA рассчитывается как `(kills + assists) / deaths`
- [ ] При deaths = 0 → KDA отображается корректно (не Infinity / не NaN)

## Последние 20 матчей

- [ ] Блок показывает максимум 20 матчей
- [ ] Если матчей меньше 20 → показывает все
- [ ] Подпись «20 игр» число отображается зелёным
- [ ] Рядом отображается WR с цветом:
  - [ ] WR ≥ 50% → зелёный
  - [ ] WR < 50% → красный
- [ ] В скобках рядом с WR — счёт W-L
- [ ] Список героев, сыгранных за эти матчи:
  - [ ] Имя героя
  - [ ] Количество игр
  - [ ] WR с цветом (≥50% зелёный, <50% красный)
- [ ] Сумма игр по героям = 20 (или = общее число матчей в блоке)
- [ ] При удалении дубликатов: один герой = одна строка с суммой игр

## Статистика за патч

- [ ] Отображается номер текущего патча
- [ ] Номер патча совпадает с актуальным на OpenDota
- [ ] Отображается количество игр за патч
- [ ] Отображается WR за патч с корректным цветом
- [ ] **Топ-5 по играм:**
  - [ ] Отображаются герои с наибольшим числом игр
  - [ ] Для каждого: имя, число игр, WR
  - [ ] Сортировка по числу игр (убывание)
  - [ ] WR выделен цветом
- [ ] **Топ-5 по WR:**
  - [ ] Отображаются герои с наивысшим винрейтом
  - [ ] Для каждого: имя, число игр, WR
  - [ ] Сортировка по WR (убывание)
  - [ ] Минимальный порог игр 3 матча
  - [ ] WR выделен цветом
- [ ] Учитываются только матчи текущего патча (не прошлых)

## Блок «ГЕРОИ»

- [ ] Отображается 10 героев с наибольшим числом матчей
- [ ] Для каждого: имя, число игр, WR
- [ ] Сортировка по числу игр (убывание)
- [ ] WR выделен цветом (≥50% зелёный, <50% красный)
- [ ] Кнопка «Всё» показывает статистику за все матчи
- [ ] Кнопка «Патч» показывает статистику за патч
- [ ] При переключении отображаются корректные герои согласно названию кнопки
- [ ] Активная кнопка визуально выделена
- [ ] «Все» показывает ≥ игр, чем «Патч»
- [ ] При «Патч» показываются только герои текущего патча

## Граничные случаи

- [ ] 0 матчей → все блоки показывают «Нет данных»
- [ ] 1 матч → W-L = 1-0 или 0-1, WR = 100% или 0%
- [ ] 19 матчей → блок 20 матчей показывает 19
- [ ] 20 матчей → блок показывает ровно 20
- [ ] 21 матч → блок показывает последние 20
- [ ] Все матчи проиграны → WR = 0%, красный
- [ ] Все матчи выиграны → WR = 100%, зелёный
- [ ] Ровно 50% WR → граница цвета (зелёный или красный — уточнить)
- [ ] Один и тот же герой в нескольких матчах → агрегируется в одну строку
- [ ] Игрок не играл в текущем патче → «Нет данных»
- [ ] Длинный ник героя → не ломает вёрстку
- [ ] 0 deaths → KDA не Infinity

## Что НЕ проверяем в этом чек-листе

- Отображение блоков (покрыто в `profile.md`)
- Пиры (покрыто в `peers.md`)
- Пустые состояния страницы (покрыто в `profile.md`)
- Навигация и доступ (покрыто в `profile.md` и `auth.md`)
- Ранг, аватар, ник (покрыто в `profile.md`)
