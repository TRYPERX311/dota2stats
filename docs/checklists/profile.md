# Чек-лист: Профиль игрока

**Модуль:** Профиль игрока
**Приоритет:** Высокий
**Окружение:** Production / Local

## Навигация

- [ ] Авторизованный: клик по Логотипу → `/me`
- [ ] Гость: клик по карточке в списке → `/profile/{id}`
- [ ] Гость: клик по логотипу → `/users`
- [ ] Прямой переход `/profile/{id}` работает для обоих
- [ ] Прямой переход `/me` для гостя → 401 или редирект

## Поля профиля

- [ ] Отображается ник (не обрезается)
- [ ] Отображается аватар (загружается, не битый)
- [ ] Отображается ранг
- [ ] Отображается иконка ранга (загружается, не битая)
- [ ] Иконка соответствует рангу
- [ ] Некалиброванный игрок → «Без ранга»

## Блоки статистики

- [ ] Блок «Основная статистика» отображается
- [ ] Блок «Последние 20 матчей» отображается
- [ ] Блок «Статистика за патч» отображается
- [ ] Внутри «Статистики за патч»: топ-5 по играм
- [ ] Внутри «Статистики за патч»: топ-5 по WR
- [ ] Блок «ГЕРОИ» (топ героев за всё время) отображается
- [ ] Переключатель Все/Патч работает

## Пиры (доступ)

- [ ] Гость не видит блок «Пиры»
- [ ] Авторизованный видит пиры в своём профиле
- [ ] Авторизованный НЕ видит пиры в чужом профиле
- [ ] API `/profile/{id}/peers` → 401 для гостя

## Пустые значения

- [ ] Нет статистики → «Матчи еще не собирались/Нет данных»
- [ ] Профиль закрыт → «Матчи еще не собирались/Нет данных»
- [ ] OpenDota недоступна → ошибка или заглушка

## API (базовые)

- [ ] `GET /profile/{id}` → 200 OK
- [ ] `GET /profile/{id}` для несуществующего  → 404
- [ ] `GET /profile/{id}` для закрытого профиля → 200 с пустыми данными или 403]
- [ ] `GET /me` для гостя → 401
- [ ] `GET /me` для авторизованного → 200 OK
- [ ] `GET /profile/{id}/peers` → 401 для гостя, 200 для авторизованного

## Граничные случаи

- [ ] Авторизованный смотрит чужой профиль
- [ ] Авторизованный смотрит свой профиль
- [ ] Несуществующий ID → 404 или заглушка
- [ ] Профиль с 0 матчей → все блоки показывают заглушки 
- [ ] Профиль с закрытой историей → корректная заглушка
- [ ] Длинный ник → не ломает вёрстку
