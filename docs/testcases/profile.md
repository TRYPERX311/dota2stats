# Тест-кейсы: Профиль

## TC-PROFILE-001: Отображение профиля авторизованного пользователя

**Модуль** Профиль (карточка пользователя)

**Приоритет:** Critical  

**Тип:** Позитивный

### Предусловия теста

1. Пользователь авторизован через Steam.
2. Пользователь имеет собранную статистику в БД.
3. Приложение доступно по адресу `http://45.86.245.140.nip.io/`.
4. Профиль содержит: ник, аватар, ранг, статистику.

### Шаги

| #  | Действие                                   | Ожидаемый результат                                                    |
|----|--------------------------------------------|------------------------------------------------------------------------|
| 1  | Проверить главную страницу                 | Отображается профиль авторизованного пользователя                      |
| 2  | Проверить URL                              | URL соответствует `/` или `/me`                                        |
| 3  | Проверить отображение ника                 | Ник отображается, не обрезается                                        |
| 4  | Проверить отображение аватара              | Аватар загружается, не битый                                           |
| 5  | Проверить отображение ранга                | Ранг отображается, иконка соответствует рангу                          |
| 6  | Проверить блок «Основная статистика»       | Отображается: W-L, WR (зелёный/красный), кол-во игр, средний KDA       |
| 7  | Проверить блок «Последние 20 матчей»       | Отображаются матчи, подпись «20 игр», WR, W-L в скобках                |
| 8  | Проверить блок «Статистика за патч»        | Отображается номер патча, кол-во игр, WR, топ-5 по играм, топ-5 по WR  |
| 9  | Проверить блок «ГЕРОИ»                     | Отображается 10 героев с наибольшим числом матчей                      |
| 10 | Проверить переключатель Все/Патч в «ГЕРОИ» | При переключении данные обновляются                                    |
| 11 | Проверить блок «Пиры»                      | Отображается список пиров (только для авторизованного в своём профиле) |
| 12 | Открыть DevTools → Console                 | Нет ошибок в консоли                                                   |
| 13 | Обновить страницу (F5)                     | Профиль отображается, сессия сохраняется                               |

### Постусловия теста

1. Сессия не изменена.
2. Данные в БД не изменены.
