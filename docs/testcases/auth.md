# Тест-кейсы: Авторизация

## TC-AUTH-001: Успешный вход через Steam

**Модуль** Авторизация

**Приоритет:** Critical

**Тип:** Позитивный

### Предусловия теста

1. Приложение доступно по адресу `http://45.86.245.140.nip.io/`
2. Пользователь имеет действующий аккаунт Steam.

### Шаги

| # | Действие                                                                    | Ожидаемый результат                                                   |
|---|-----------------------------------------------------------------------------|-----------------------------------------------------------------------|
| 1 | Открыть `http://45.86.245.140.nip.io/`                                      | Главная страница загружается, отображается кнопка «Войти через Steam» |
| 2 | Кликнуть по кнопке «Войти через Steam»                                      | Редирект на `steamcommunity.com/openid/login`                         |
| 3 | Ввести логин и пароль Steam или отсканировать QR-код в мобильном приложении | Успешная авторизация в Steam                                          |
| 4 | Подтвердить вход (если требуется)                                           | Редирект обратно на приложение                                        |
| 5 | Дождаться загрузки главной страницы                                         | Редирект на `/` или `/me`                                             |
| 6 | Проверить отображение                                                       | Кнопка «Войти» скрыта, отображается профиль пользователя              |
| 7 | Проверить cookie                                                            | Установлена cookie `session`                                          |
| 8 | Обновить страницу (F5)                                                      | Сессия сохраняется, пользователь остаётся авторизованным              |

### Постусловия

- Пользователь авторизован
- В БД создана запись о новом пользователе (если новый)
- Запущен фоновый сбор статистики (для нового пользователя)
