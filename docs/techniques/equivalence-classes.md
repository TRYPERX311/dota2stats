# Классы эквивалентности и граничные значения

## 1. `rank_to_str(rank_tier)` — `ranks.py`

Функция преобразует числовой `rank_tier` (например, `53`) в строку (например, `"Legend 3"`). Используется для
отображения ранга в профиле.

### Классы эквивалентности

| Класс                       | Пример входа     | Ожидаемый выход                          | Пояснение                      |
|-----------------------------|------------------|------------------------------------------|--------------------------------|
| Пустой вход                 | `None`           | `"Calibrating"`                          | Пользователь не откалиброван   |
| Нулевой вход                | `0`              | `"Calibrating"`                          | `0` в Python falsy, как `None` |
| Отрицательный               | `-1`, `-100`     | `"Unknown"`                              | Некорректный вход              |
| Валидный tier 1–7, star 1–5 | `53`, `15`, `71` | `"Legend 3"`, `"Herald 5"`, `"Divine 1"` | Нормальный ранговый случай     |
| Валидный tier 1–7, star = 0 | `10`, `20`, `70` | `"Unknown"`                              | Звёзд не бывает 0              |
| Валидный tier 1–7, star > 5 | `16`, `26`, `76` | `"Unknown"`                              | Максимум звёзд — 5             |
| Immortal (tier 8)           | `80`, `85`, `86` | `"Immortal"`                             | Звёзды у Immortal игнорируются |
| tier > 8                    | `90`, `128`      | `"Unknown"`                              | Нет такого ранга               |

### Граничные значения

| Граница                  | Вход     | Ожидание                     | Почему важно                        |
|--------------------------|----------|------------------------------|-------------------------------------|
| Переход 0 → 1            | `0`, `1` | `"Calibrating"`, `"Unknown"` | `0` falsy, `1` → tier=0 (нет ранга) |
| Минимум валидного        | `11`     | `"Herald 1"`                 | Начало диапазона                    |
| Максимум star            | `15`     | `"Herald 5"`                 | Последний валидный star             |
| За границей star         | `16`     | `"Unknown"`                  | Первый невалидный star              |
| Минимум Divine           | `71`     | `"Divine 1"`                 | Начало Divine                       |
| Максимум tier 7          | `75`     | `"Divine 5"`                 | Последний валидный не-Immortal      |
| За границей tier 7       | `76`     | `"Unknown"`                  | Первый невалидный                   |
| Immortal                 | `80`     | `"Immortal"`                 | Единственный валидный для tier 8    |
| Верхняя граница Immortal | `85`     | `"Immortal"`                 | Игнорирует star                     |
| За границей Immortal     | `86`     | `"Immortal"`                 | Всё ещё tier 8, star игнорируется   |
| Переход в Unknown        | `90`     | `"Unknown"`                  | tier=9, нет в RANK_NAMES            |
| Отрицательная граница    | `-1`     | `"Unknown"`                  | Проверка `tier not in RANK_NAMES`   |

## 2. `winrate(wins, games)` — `utils.py` / `main.py`

Функция вычисляет процент побед. Используется для отображения винрейта в профиле, героях, патче.

### Классы эквивалентности

| Класс                   | Пример входа      | Ожидаемый выход | Пояснение                               |
|-------------------------|-------------------|-----------------|-----------------------------------------|
| Нет игр                 | `winrate(0, 0)`   | `0.0`           | Деление на ноль предотвращено           |
| Все поражения           | `winrate(0, 10)`  | `0.0`           | `wins = 0`                              |
| Все победы              | `winrate(10, 10)` | `100.0`         | `wins = games`                          |
| Часть побед             | `winrate(5, 10)`  | `50.0`          | Обычный случай                          |
| Округление до 2 знаков  | `winrate(1, 3)`   | `33.33`         | Проверка округления                     |
| Аномалия (wins > games) | `winrate(11, 10)` | `110.0`         | Функция не защищена, но должно работать |

### Граничные значения

| Граница               | Вход                | Ожидание | Почему важно              |
|-----------------------|---------------------|----------|---------------------------|
| `games = 0`           | `winrate(0, 0)`     | `0.0`    | Защита от деления на ноль |
| `games = 1, wins = 0` | `winrate(0, 1)`     | `0.0`    | Минимум                   |
| `games = 1, wins = 1` | `winrate(1, 1)`     | `100.0`  | Максимум                  |
| Округление вниз       | `winrate(1, 3)`     | `33.33`  | Проверка `round(..., 2)`  |
| Округление вверх      | `winrate(2, 3)`     | `66.67`  | Проверка `round(..., 2)`  |
| `wins = games = 100`  | `winrate(100, 100)` | `100.0`  | Большое значение          |
| Аномалия              | `winrate(11, 10)`   | `110.0`  | Функция не падает         |

## 3. `ts_to_dt(ts)` — `utils.py`

Функция преобразует Unix timestamp в `datetime` (UTC, без таймзоны).

### Классы эквивалентности

| Класс                             | Пример входа | Ожидаемый выход                      | Пояснение             |
|-----------------------------------|--------------|--------------------------------------|-----------------------|
| Пустой вход                       | `None`       | `None`                               | Нет данных            |
| Нулевой вход                      | `0`          | `None`                               | `0` falsy, как `None` |
| Валидный timestamp                | `1700000000` | `datetime(2023, 11, 14, 22, 13, 20)` | Обычный случай        |
| Отрицательный timestamp (до 1970) | `-1`         | `datetime(1969, 12, 31, 23, 59, 59)` | Работает, но редко    |
| Очень большой timestamp           | `9999999999` | `datetime(2286, 11, 20, 17, 46, 39)` | Год 2286              |

### Граничные значения

| Граница          | Вход         | Ожидание                        | Почему важно                     |
|------------------|--------------|---------------------------------|----------------------------------|
| `None` vs `0`    | `None`, `0`  | `None`, `None`                  | Оба falsy                        |
| Минимум          | `1`          | `datetime(1970, 1, 1, 0, 0, 1)` | Первая секунда                   |
| Переход в 2000-е | `946684800`  | `datetime(2000, 1, 1, 0, 0, 0)` | Известная дата                   |
| Очень большое    | `9999999999` | `datetime(2286, ...)`           | Проверка отсутствия переполнения |

## 4. `wl_from_match(m, account_id)` — `utils.py`

Функция определяет, победил ли игрок в матче (1 — победа, 0 — поражение, None — не удалось определить).

### Классы эквивалентности

| Класс                          | Пример `m`                                   | Ожидание | Пояснение         |
|--------------------------------|----------------------------------------------|----------|-------------------|
| Нет `radiant_win`              | `{}`                                         | `None`   | Не хватает данных |
| Нет `player_slot`              | `{"radiant_win": True}`                      | `None`   | Не хватает данных |
| Radiant победил, игрок Radiant | `{"radiant_win": True, "player_slot": 0}`    | `1`      | Победа            |
| Radiant победил, игрок Dire    | `{"radiant_win": True, "player_slot": 128}`  | `0`      | Поражение         |
| Dire победил, игрок Radiant    | `{"radiant_win": False, "player_slot": 0}`   | `0`      | Поражение         |
| Dire победил, игрок Dire       | `{"radiant_win": False, "player_slot": 128}` | `1`      | Победа            |

### Граничные значения

| Граница                   | `player_slot` | `radiant_win` | Ожидание | Почему важно              |
|---------------------------|---------------|---------------|----------|---------------------------|
| Минимум Radiant           | `0`           | `True`        | `1`      | Первый Radiant            |
| Максимум Radiant          | `127`         | `True`        | `1`      | Последний Radiant         |
| Переход в Dire            | `128`         | `True`        | `0`      | Первый Dire               |
| Максимум Dire             | `255`         | `True`        | `0`      | Последний Dire            |
| `radiant_win` отсутствует | `—`           | `—`           | `None`   | Защита от неполных данных |
| `player_slot` отсутствует | `0`           | `—`           | `None`   | Защита от неполных данных |

## 5. `get_hero_name(hero_id)` — `heroes.py`

Функция возвращает локализованное имя героя по ID.

### Классы эквивалентности

| Класс                     | Пример входа | Ожидаемый выход    | Пояснение      |
|---------------------------|--------------|--------------------|----------------|
| Валидный hero_id          | `1`          | `"Anti-Mage"`      | Есть в словаре |
| Валидный hero_id (другой) | `2`          | `"Axe"`            | Есть в словаре |
| Невалидный hero_id        | `9999`       | `"Unknown (9999)"` | Нет в словаре  |
| Нулевой hero_id           | `0`          | `"Unknown (0)"`    | Нет в словаре  |
| Отрицательный             | `-1`         | `"Unknown (-1)"`   | Нет в словаре  |

### Граничные значения

| Граница            | Вход  | Ожидание          | Почему важно                |
|--------------------|-------|-------------------|-----------------------------|
| Минимум в словаре  | `1`   | `"Anti-Mage"`     | Первый герой                |
| Максимум в словаре | `145` | `"KeZ"`           | Последний герой (если есть) |
| За границей        | `146` | `"Unknown (146)"` | Нет в словаре               |
| `0`                | `0`   | `"Unknown (0)"`   | Нет в словаре               |
| Отрицательный      | `-1`  | `"Unknown (-1)"`  | Нет в словаре               |
